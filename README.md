# BADANG Trading 1.2

1.0의 점수 카드 스타일을 참고한 모바일 분석 도구. 단타(5m/15m/1H), 스윙(1H/4H/1D), BTC/ETH 등 주요 코인 상시 표시, 롱/숏 규칙 점수, 캔들 기반 거래대금 압력 추정, ATR/스윙 손절 및 R배수 익절 시나리오. **주문 기능 없음.**

## 설치 / Render
Build: `pip install -r requirements.txt`
Start: `gunicorn app:app --bind 0.0.0.0:$PORT`

## 주의
- 거래대금 방향은 양봉/음봉을 기준으로 추정한 값입니다. 실제 체결별 CVD, 자금 순유입, 매집을 측정하지 않습니다. OI와 펀딩비는 아직 수집하지 않으므로 미확인으로 표시합니다.
- 점수는 수익 확률이 아닙니다. 상위봉 추세, 수급 추정, 점수, 다이버전스 필터를 모두 통과해야 후보로 표시합니다.
- 진입가는 마지막 확정봉 종가로 계산한 가상 시나리오입니다. 익절가는 1.5R/2.5R(단타) 또는 2R/3R(스윙), 손절은 스윙 구조와 ATR을 사용합니다. 실제 시장가와 다를 수 있습니다.
- API 호출이 많아 무료 호스팅에서 느리거나 제한될 수 있습니다. 백테스트/실거래 검증 없음.
